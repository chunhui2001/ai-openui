Vite 怎样构建多页面

Vite 的打包入口是 HTML，不是 JS。每个带 <script type="module"> 的 HTML 是一条独立的 Rollup 链。

HTML 放在 src/，Vite root 指向该目录，所以 /about/ 在 make run 时就能打开。但 vite build 默认只打 root 下的 index.html。要把本页打进 dist/about/index.html，必须在 vite.config.ts 的 build.rollupOptions.input 里同时列出： 

input: {
  index: resolve(rootDir, 'src/index.html'),
  playground: resolve(rootDir, 'src/ai-playground/index.html'),
  about: resolve(rootDir, 'src/about/index.html'),
}

本页入口是 src/about/about.ts，首页是 src/home/home.ts，对话页是 src/ai-playground/ai-playground.ts（/ai-playground/）。各自先 import base.css，再引对应 CSS。h2o 的 file.dir 指向 dist/ 后，/about/ 会落到 about/index.html。线上路径没有 /src/ 前缀。
