首页 Playground 关于

Button · variant

四种外观：primary、secondary（默认）、ghost、danger。

createButton({ label: '保存', variant: 'primary' })
createButton({ label: '取消', variant: 'secondary' })
createButton({ label: '更多', variant: 'ghost' })
createButton({ label: '删除', variant: 'danger' })

Button · size

sm 与默认 md。

createButton({ label: '小按钮', size: 'sm' })
createButton({ label: '中按钮', size: 'md' })

Button · disabled

禁用后不可点，样式降低透明度。

createButton({ label: '不可用', variant: 'primary', disabled: true })

Button · onClick

点击计数，确认回调生效。

还没点过

createButton({
  label: '点我',
  variant: 'primary',
  onClick: () => { count += 1 },
})

Button · HTML class

不经过工厂函数，也可以直接写 class。

<button type="button" class="ui-button ui-button--primary ui-button--md">
  保存
</button>
